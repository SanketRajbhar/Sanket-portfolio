Sanket Rajbhar — Portfolio (HTML + CSS only, no JavaScript)

Files
  index.html   all content
  styles.css   all styling

Open index.html in any browser, or upload both files to any static host.

Placeholders appear as [BRACKETED TEXT] with a dashed orange outline.
Search index.html for "[" to find every one. For a placeholder link, replace
the text and add an href="..." attribute to its <a> tag (remove aria-disabled
and class "is-ph"). For the contact form, add your email:
  <form class="form" action="mailto:you@example.com" method="post" enctype="text/plain">
and remove the "disabled" attribute from the submit button.
